# budget_book

혼자 사용하는 간단한 가계부 웹 앱입니다. 로그인 없이 브라우저에서 수입과 지출을 기록하고, 월별 수입 합계·지출 합계·잔액을 확인합니다. 거래 데이터는 서버를 실행하는 컴퓨터의 SQLite 파일 `budget.db`에 저장됩니다.

## 현재 상태

- MVP(v0.1 ~ v0.3), v0.4, v0.5, v0.6이 구현되어 있습니다: 거래 등록·조회·수정·삭제, 월별 요약, 사용자 분류 추가·이름 수정·삭제, 백업 파일 다운로드, 분류별 필터.
- API 테스트 226개와 샘플 테스트 1개가 모두 통과합니다.
- 화면 동작(`docs/TEST_CASES.md` 2장)은 브라우저에서 직접 확인합니다.

## MVP 기능

- 수입·지출 거래 등록, 조회, 수정, 삭제
- 거래 항목: 거래일, 유형(수입/지출), 금액, 분류, 메모(선택)
- 고정 분류 목록
  - 지출: 식비, 교통, 주거, 쇼핑, 의료, 문화·여가, 기타
  - 수입: 월급, 용돈, 기타
- 연·월을 선택해 해당 월의 거래 목록 조회 (거래일 → 등록 시각 → ID 내림차순)
- 월별 요약: 수입 합계, 지출 합계, 잔액(수입 합계 - 지출 합계)
- 금액은 원 단위 정수로 저장하고 `12,500원` 형식으로 표시
- 삭제 전 확인 창 표시, 삭제한 거래는 복구 불가

## v0.4 기능: 사용자 분류

- 입력 폼 아래 `분류 관리` 카드에서 수입·지출 분류를 추가하고, 추가한 분류의 이름을 수정하거나 삭제
- 기본 분류는 수정·삭제할 수 없음
- 같은 유형 안에서는 이름 중복 불가 (기본 분류 포함), 이름은 1~20자
- 이름을 수정하면 그 분류를 쓰던 기존 거래의 분류도 함께 바뀜
- 거래가 있는 분류는 삭제할 수 없음 (사용 중인 건수 안내)
- 이전 버전에서 쓰던 `budget.db`도 그대로 사용 가능 (서버 시작 시 분류 테이블 자동 추가)

## v0.6 기능: 분류별 필터

- 거래 내역 카드의 `분류 필터`에서 분류를 고르면 그 달의 해당 분류 거래만 보이고, `식비(지출) · 2건 · 합계 20,500원`처럼 건수와 합계가 표시됨
- 지출 `기타`와 수입 `기타`처럼 이름이 같아도 유형이 다르면 따로 걸러짐
- 월을 바꿔도 필터가 유지되어 달마다 같은 분류를 비교할 수 있음 (월별 요약은 항상 그 달 전체 기준)

## 설치와 실행 (Windows PowerShell 기준)

Python 3.12가 필요합니다.

```powershell
# 가상환경 만들기
python -m venv .venv

# 의존성 설치
.venv\Scripts\python -m pip install -r requirements.txt

# 서버 실행 후 브라우저에서 http://127.0.0.1:8000 접속
.venv\Scripts\python -m uvicorn app.main:app --reload

# 테스트 실행
.venv\Scripts\python -m pytest tests
```

- 처음 실행하면 프로젝트 폴더에 `budget.db`가 자동으로 만들어집니다.
- API 문서는 http://127.0.0.1:8000/docs 에서 볼 수 있습니다. 에러 응답은 이 화면의 예시와 달리 `docs/API_SPEC.md`의 `{ "error": { "code", "message" } }` 형식을 따릅니다.
- 테스트는 임시 DB 파일을 사용하므로 `budget.db`를 건드리지 않습니다.
- 로그인 기능이 없으므로 서버를 외부에 공개하지 마세요. 기본 설정(`127.0.0.1`)은 내 컴퓨터에서만 접속할 수 있습니다.

## 데이터 백업

### 백업 (v0.5)

화면 상단 제목 옆의 **백업 다운로드** 버튼을 누르면 `budget-backup-2026-10-30-1530.db`처럼 날짜와 시각이 들어간 백업 파일이 브라우저로 다운로드됩니다. 거래 내역과 분류가 모두 들어 있고, 서버가 실행 중이어도 안전하게 만들어집니다. 받은 파일은 다른 드라이브나 클라우드 등 안전한 곳에 보관하세요.

### 복원 (수동)

앱에는 복원 기능이 없습니다. 백업 파일로 되돌리려면 아래 순서를 따르세요.

1. 서버를 끕니다.
2. 프로젝트 폴더의 지금 `budget.db`를 다른 이름(예: `budget-old.db`)으로 바꿔 보관합니다.
3. 되돌릴 백업 파일을 프로젝트 폴더에 넣고 이름을 `budget.db`로 바꿉니다.
4. 서버를 켜면 백업 시점의 거래 내역과 분류가 보입니다.

다른 컴퓨터에서 같은 데이터를 쓸 때도 같은 방법으로 백업 파일을 `budget.db`로 넣으면 됩니다.

- `budget.db`와 백업 파일은 개인 거래 데이터이므로 git에 올리지 마세요. (`.gitignore`가 프로젝트 폴더의 `*.db` 파일을 모두 제외합니다)

## 알려진 제한

- **아주 큰 합계:** 한 달 합계가 약 9천조 원(9,007,199,254,740,991)을 넘으면 브라우저가 숫자를 정확히 표시하지 못할 수 있습니다. 일반적인 가계부 금액에서는 일어나지 않습니다.
- **분류 이름 수정 중 선택값:** 입력 폼에서 선택해 둔 분류의 이름을 바꾸면, 그 선택이 `분류 선택`으로 초기화됩니다. 다시 고르면 됩니다.
- **월 선택 칸:** 연·월 선택 칸(`<input type="month">`)을 지원하지 않는 브라우저에서는 일반 입력칸으로 보입니다. 이때는 `2026-10`처럼 입력하면 됩니다.
- **개발 서버 자동 재시작:** `--reload`로 실행한 서버가 코드 변경 후 가끔 재시작을 멈추고 예전 코드로 동작할 수 있습니다. 화면이 이상하면 서버를 껐다 켜세요.

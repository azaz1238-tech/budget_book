# PRD 초안 - 개인 가계부

## 1. 목표

- 혼자 사용하는 웹 브라우저 기반 가계부를 제공한다.
- 로그인 없이 수입과 지출 내역을 간단히 등록하고 관리할 수 있게 한다.
- 월별 수입 합계, 지출 합계, 잔액을 확인할 수 있게 한다.
- 거래 데이터는 서버 컴퓨터의 SQLite `budget.db` 파일에 저장한다.

## 2. 대상 사용자

- 가계부를 개인적으로 혼자 사용하는 사용자
- 계정 생성이나 로그인을 원하지 않는 사용자
- 웹 브라우저로 가계부에 접속하는 사용자

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 거래 내역 등록 | 수입 또는 지출 유형, 거래일, 금액, 기본 분류를 입력해 내역을 저장한다. 메모는 선택 입력이다. |
| F-02 | 기본 분류 제공 | 지출 분류(식비, 교통, 주거, 쇼핑, 의료, 문화·여가, 기타)와 수입 분류(월급, 용돈, 기타)를 제공한다. MVP에서는 분류를 추가·수정·삭제할 수 없다. |
| F-03 | 거래 내역 조회 | 저장된 내역을 목록으로 확인하고 연·월을 선택해 해당 월의 내역을 조회한다. |
| F-04 | 거래 내역 정렬 | 내역을 거래일 내림차순으로 표시한다. 거래일이 같으면 나중에 등록한 내역을 먼저 표시한다. |
| F-05 | 거래 내역 수정 | 기존 내역의 거래 유형, 거래일, 금액, 분류, 메모를 수정한다. |
| F-06 | 거래 내역 삭제 | 삭제 대상 확인 후 내역을 삭제한다. 삭제한 내역은 복구할 수 없다. |
| F-07 | 월별 요약 | 선택한 달의 수입 합계, 지출 합계, 잔액을 표시한다. 잔액은 수입 합계에서 지출 합계를 뺀 값이다. |
| F-08 | 금액 입력 및 표시 | 금액을 원 단위 정수로 저장한다. 화면에는 천 단위 콤마와 `원`을 붙여 표시한다. |
| F-09 | 데이터 저장 | 거래 내역을 서버 컴퓨터의 SQLite `budget.db`에 저장하고 서버 재실행 후에도 유지한다. 브라우저를 바꿔도 같은 서버의 데이터를 조회할 수 있다. |
| F-10 | 사용자 분류 편집 (v0.4) | 수입·지출 유형별로 분류를 추가하고, 추가한 분류의 이름을 수정하거나 삭제한다. 기본 분류는 바꿀 수 없다. 같은 유형 안에서는 이름이 중복될 수 없다. 이름을 수정하면 기존 거래의 분류도 바뀌고, 거래가 있는 분류는 삭제할 수 없다. |
| F-11 | 데이터베이스 백업 (v0.5) | 화면 상단 제목 옆 버튼으로 `budget.db` 백업 파일을 브라우저에 다운로드한다. 파일 이름에 날짜와 시각을 넣는다. 복원은 앱에서 제공하지 않고 README에 수동 방법을 안내한다. |
| F-12 | 분류별 필터 (v0.6) | 거래 목록에서 분류를 골라 선택한 월의 그 분류 거래만 보고, 건수와 합계를 확인한다. 유형이 다르면 같은 이름도 다른 분류로 본다. 월을 바꿔도 필터는 유지되고, 월별 요약은 그 달 전체 기준이다. |
| F-13 | 월 이동 버튼 (v0.7) | 이전 달·다음 달·이번 달 버튼으로 조회 월을 바꾼다. 연도가 바뀌는 경우도 처리하고, 필터는 유지한다. |
| F-14 | 분류별 지출 합계 (v0.8) | 선택한 달의 지출을 분류별로 합쳐 합계·건수·비율을 큰 순서의 막대 목록으로 보여 준다. 차트 라이브러리는 쓰지 않는다. |
| F-15 | 검색·필터 (v0.9) | 선택한 달 안에서 유형, 분류, 메모 검색어로 거래를 거르고 결과 건수와 합계를 확인한다. |
| F-16 | 분류별 월 예산 (v0.10) | 지출 분류마다 모든 달에 적용되는 월 예산을 정하고, 분류별 지출에서 사용률과 남은 금액을 확인한다. |
| F-17 | 고정 거래 (v0.11) | 매달 같은 거래를 고정 거래로 등록해 두고, 버튼으로 그 달에 한 번에 추가한다. 같은 달에 중복으로 추가되지 않는다. |

## 4. 사용자 스토리

- 혼자 가계부를 쓰는 사용자로서, 수입이나 지출 내역을 기록하고 싶다.
- 거래를 기록하는 사용자로서, 거래일과 금액, 알맞은 분류를 지정하고 메모는 필요할 때만 남기고 싶다.
- 거래 내역을 관리하는 사용자로서, 저장한 내역을 확인하고 잘못 입력한 내용을 수정하고 싶다.
- 거래 내역을 정리하는 사용자로서, 더 이상 필요 없는 내역을 삭제하고 싶다.
- 지출과 수입을 파악하려는 사용자로서, 원하는 달의 거래 목록과 월별 합계를 확인하고 싶다.
- 월별 현황을 확인하는 사용자로서, 해당 월의 수입과 지출 차이를 잔액으로 확인하고 싶다.
- 로그인 없이 사용하는 사용자로서, 브라우저를 바꾸더라도 서버에 저장된 같은 거래 내역을 보고 싶다.
- 내 생활에 맞게 분류하고 싶은 사용자로서, 기본 분류에 없는 분류를 추가하고 이름을 고치거나 필요 없어진 분류를 지우고 싶다. (v0.4)
- 데이터를 잃고 싶지 않은 사용자로서, 버튼 하나로 가계부 데이터를 파일로 받아 따로 보관하고 싶다. (v0.5)
- 돈의 흐름을 파악하려는 사용자로서, 어떤 분류에서 얼마를 쓰고 얼마를 벌었는지 분류별로 골라 확인하고 싶다. (v0.6)
- 여러 달을 오가며 보는 사용자로서, 달력을 열지 않고 버튼 한 번으로 이전·다음 달과 이번 달로 이동하고 싶다. (v0.7)
- 지출을 줄이고 싶은 사용자로서, 이번 달 어떤 분류에 돈을 가장 많이 썼는지 한눈에 보고 싶다. (v0.8)
- 특정 거래를 찾는 사용자로서, 메모 키워드와 유형, 분류로 그 달의 거래를 골라 보고 싶다. (v0.9)
- 계획적으로 쓰고 싶은 사용자로서, 분류마다 한 달 예산을 정하고 얼마나 남았는지 확인하고 싶다. (v0.10)
- 매달 같은 거래를 적는 사용자로서, 월세·구독료·월급 같은 거래를 매번 입력하지 않고 한 번에 넣고 싶다. (v0.11)

## 5. 범위 밖

- 회원가입, 로그인, 여러 사용자 지원
- 기기 간 데이터 동기화 및 온라인 백업
- 앱 내 데이터베이스 백업 버튼 (v0.5에서 제공 예정, F-11)
- 앱 내 백업 복원 기능 (README의 수동 복원 방법으로 대신함)
- 사용자 분류 추가·수정·삭제 (v0.4에서 제공 예정, F-10)
- 분류별 월 예산 (v0.10에서 제공 예정, F-16), 고정 거래 불러오기 (v0.11에서 제공 예정, F-17)
- 알림, 정해진 날에 거래를 자동으로 등록하는 스케줄러
- 영수증 촬영 및 자동 분류
- 은행 계좌 연동 및 자동 거래 가져오기
- 차트 라이브러리를 쓰는 통계 차트, 여러 달 추이 그래프 (분류별 지출 막대 목록은 v0.8, F-14)
- 파일 내보내기
- 삭제한 거래 복구

## 6. 성공 기준

- 사용자는 로그인 없이 수입과 지출 내역을 등록하고 조회할 수 있다.
- 등록한 내역을 수정하거나 삭제할 수 있으며, 삭제는 사용자가 확인한 경우에만 수행된다.
- 거래 내역에 수입 또는 지출의 기본 분류를 지정할 수 있고, MVP에서는 기본 분류 목록이 변경되지 않는다.
- 금액은 원 단위 정수로 저장되고 화면에 천 단위 콤마와 `원`을 붙여 표시한다.
- 원하는 월의 수입 합계와 지출 합계가 해당 월의 내역을 기준으로 표시된다.
- 잔액은 선택한 월의 수입 합계에서 지출 합계를 뺀 값과 일치한다.
- 서버를 재실행하거나 브라우저를 변경해도 서버의 `budget.db`에 저장된 내역을 확인할 수 있다.

### v0.4 성공 기준

- 사용자는 수입·지출 유형별로 분류를 추가하고 거래에 지정할 수 있다.
- 기본 분류는 변경되지 않으며, 같은 유형 안에서 이름이 중복된 분류는 만들어지지 않는다.
- 사용자 분류의 이름을 수정하면 그 분류를 쓰던 거래 내역에도 새 이름이 표시된다.
- 거래가 있는 분류는 삭제되지 않고, 거래가 없는 사용자 분류만 삭제된다.

### v0.5 성공 기준

- 사용자는 화면 상단의 백업 버튼으로 날짜와 시각이 들어간 이름의 백업 파일을 받을 수 있다.
- 백업 파일로 바꿔 넣고 서버를 실행하면 백업 시점의 데이터가 그대로 보인다.
- 백업해도 기존 데이터는 바뀌지 않고, 실패하면 오류가 안내된다.

### v0.6 성공 기준

- 사용자는 분류를 골라 선택한 월의 그 분류 거래와 건수·합계를 볼 수 있다.
- 이름이 같아도 유형이 다른 분류의 거래는 섞이지 않는다.
- 필터 상태에서 거래를 바꾸면 목록과 합계가 바로 맞게 바뀐다.

### v0.7 성공 기준

- 사용자는 버튼으로 이전·다음 달과 이번 달로 이동할 수 있고, 연도가 바뀌어도 맞게 이동한다.

### v0.8 성공 기준

- 사용자는 선택한 달에 어느 분류에 얼마를 썼는지 큰 순서의 막대 목록으로 확인할 수 있다.
- 분류별 합계를 모두 더하면 월별 요약의 지출 합계와 같다.

### v0.9 성공 기준

- 사용자는 유형·분류·메모 검색어로 거래를 걸러 원하는 거래와 그 합계를 찾을 수 있다.

### v0.10 성공 기준

- 사용자는 지출 분류마다 월 예산을 정하고, 분류별 사용률과 남은 금액(초과 금액)을 확인할 수 있다.

### v0.11 성공 기준

- 사용자는 고정 거래를 등록해 두고 버튼 한 번으로 그 달에 추가할 수 있으며, 같은 달에 중복으로 추가되지 않는다.

# 가계부 아이디어

## 한 문장 정의

간단한 가계부를 만들어 수입과 지출을 관리한다.

## 누가 쓰는가

- 나 혼자 사용한다.
- 로그인은 제공하지 않는다.
- 웹 브라우저에서 사용한다.
- 서버는 FastAPI로 실행하고, 거래 데이터는 서버 컴퓨터의 SQLite `budget.db` 파일에 저장한다.

## 꼭 필요한 기능 (MVP)

- 수입 또는 지출 내역을 등록한다.
- 내역에 날짜, 금액, 분류를 입력하고 메모는 선택적으로 입력한다.
- 지출 분류(식비, 교통, 주거, 쇼핑, 의료, 문화·여가, 기타)와 수입 분류(월급, 용돈, 기타)를 제공하며 MVP에서는 목록을 추가·수정·삭제할 수 없다.
- 등록한 내역을 목록에서 확인하고 수정하거나 삭제한다.
- 월별 수입 합계, 지출 합계, 잔액(수입 합계 - 지출 합계)을 확인한다.
- 금액은 원 단위 정수로 저장하고 화면에는 천 단위 콤마와 '원'을 붙여 표시한다.
- 거래 내역은 서버를 실행하는 컴퓨터의 `budget.db`에 저장한다. 브라우저를 바꿔도 같은 데이터가 보이며, 다른 컴퓨터에서 사용하려면 DB 파일을 복사한다.

## 지금은 빼는 기능

- 회원가입, 로그인, 여러 사용자 지원
- 기기 간 동기화 및 온라인 백업
- 앱 내 DB 백업 버튼 (v0.5에서 추가 예정)
- 사용자 분류 추가·수정·삭제 (v0.4에서 추가 예정)
- 예산 설정, 반복 거래, 알림
- 영수증 촬영 및 자동 분류
- 은행 계좌 연동, 자동 거래 가져오기
- 통계 차트와 파일 내보내기

## 버전 로드맵

### v0.1 — 기본 화면과 저장

- FastAPI와 SQLite를 연결하고 `budget.db`에 거래 내역을 저장한다.
- 웹 브라우저용 기본 화면을 만든다.

### v0.2 — 거래 내역 관리

- 고정 기본 분류와 함께 거래 내역 등록, 목록 조회, 수정, 삭제를 구현한다.
- 입력 검증, 확인 삭제, 목록 정렬을 구현한다.

### v0.3 — 월별 요약

- 월별 수입과 지출 합계, 잔액(수입 합계 - 지출 합계)을 표시한다.
- 월별 내역을 확인할 수 있게 한다.

### v0.4 — 사용자 분류 편집

- 기본 분류 외 사용자 분류를 추가하고, 추가한 분류의 이름을 수정하거나 삭제할 수 있게 한다.
- 기본 분류는 그대로 둔다. 같은 유형 안에서는 분류 이름이 중복될 수 없다.
- 분류 이름을 바꾸면 그 분류를 쓰던 기존 거래의 분류도 바뀐다. 거래가 있는 분류는 삭제할 수 없다.

### v0.5 — 데이터베이스 백업

- `budget.db`를 백업할 수 있는 앱 내 기능을 추가한다.
- 화면 상단 제목 옆의 버튼을 누르면 백업 파일이 브라우저로 다운로드된다. 파일 이름에는 날짜와 시각을 넣는다.
- 백업 파일을 다시 넣는 복원은 앱에서 제공하지 않고, README에 수동 복원 방법을 안내한다.

### v1.0 — 안정화 및 첫 정식 버전

- 핵심 흐름과 데이터 저장을 점검하고 사용 가능한 첫 정식 버전을 완성한다.
